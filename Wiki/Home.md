# Welcome to SQL Nexus

SQL Nexus is a tool that helps you identify the root cause of SQL Server performance issues. It loads and analyzes performance data collected by [SQL LogScout](https://github.com/microsoft/sql_logscout) or [PSSDIAG/SQLDiag](https://github.com/microsoft/diagmanager), and offers rich, interactive reports to help you quickly pinpoint bottlenecks.
